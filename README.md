# Portfólio — Pedro Augusto

Versão local, estática e pronta para o GitHub Pages. Não depende de instalação, banco de dados ou serviços externos.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie **todo o conteúdo desta pasta**, inclusive a pasta `assets`.
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/(root)`.
5. Salve. O GitHub mostrará o endereço público do portfólio em alguns minutos.

As imagens e os vídeos foram preparados nos formatos WebP e WebM quando aplicável, priorizando compatibilidade e carregamento no navegador.

## Revisão antes de publicar

Esta versão reúne todo o material fornecido, incluindo o currículo em PDF. Antes de tornar o repositório público, revise os dados pessoais presentes no currículo e mantenha no site apenas o que deseja divulgar.
